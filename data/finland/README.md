# data/finland — local GeoJSON conversions (Supabase GeoPackages)

Generated by `node tools/finland-convert-gpkg.mjs` (run it where the Supabase
bucket `Harti/Finlanda` is reachable). Contains one EPSG:4326 GeoJSON per
source GeoPackage (`rky_piste.geojson`, `VARK_aluerajaukset.geojson`, …),
optional `<name>.style.json` colour schemes extracted from the .qml sidecars,
and `conversion-report.json` (layer inventory, feature counts, dedup
comparison). The originals in the bucket are never modified.

The "Local files (Supabase)" section of the Finland layer group reads these
same-origin files first and falls back to the `converted/` mirror in the
bucket. Until the conversion runs, those rows show an honest
"not converted yet" status. See FINLAND_LAYERS.md §local-files.
